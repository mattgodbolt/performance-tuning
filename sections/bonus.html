Bonus: std::format

"Someone always asks: what about std::format?" Modern, type-safe, but not free.

What about std::format?

  • C++20, type-safe, no printf format-string footguns
  • What you'd write today instead of stringstream

/// hide
#include <format>
#include <string>
#include <string_view>
/// unhide
std::string newOrder(std::string_view stock,
                     int price, int quantity) {
  return std::format("NEW {} {} {}",
                     stock, price, quantity);
}

std::format_to - in-place

If you already own the buffer (à la Take Two):


/// hide
#include <format>
/// unhide
void newOrder(char *buf, const char *stock,
              int price, int quantity) {
  std::format_to(buf, "NEW {} {} {}",
                 stock, price, quantity);
}

fmt::format_to - upstream

fmtlib/fmt is the upstream of std::format: 

#include <fmt/core.h>

void newOrder(char *buf, const char *stock,
              int price, int quantity) {
  fmt::format_to(buf, "NEW {} {} {}",
                 stock, price, quantity);
}
Same API. Different libstdc++ vs fmtlib implementations - and the throughput numbers say they're not equivalent.

Is it free?

Version ns / order
stringstream ~580
sprintf ~270
std::format ~310
std::format_to ~310
fmt::format_to ~210
custom Format ~80
"best" ~76
  • std::format ≈ sprintf - type-safe, not faster
  • fmt::format_to ~25% faster than sprintf - same API, different implementation
  • Asm: sprintf → ~9 lines · std::format → ~25k lines
  • For the last 2.5×, the custom Format still wins
Surprised me on the std::format result - I'd assumed it would be close to custom-Format because libstdc++ uses similar two-digit tricks. The integer formatting kernel is fast; the iterator/sink machinery wrapped around it isn't. fmtlib (the upstream) does the same job with less plumbing overhead and lands roughly halfway between sprintf and the custom Format. The 25k asm lines are everything inlined in CE - most of it is cold paths for non-integer types - but it's a useful signal of how much template machinery is in flight.
